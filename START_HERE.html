Generate on macOS or Linux

In this extracted folder, run bash setup.sh, then bash start.sh. Setup selects a compatible Python 3.11–3.13, creates the local environment, installs dependencies and verifies the core. On macOS, FloorForge.command is the double-click developer launcher.

Generate on Windows

Install Python 3.11–3.13 with its launcher. Extract the folder and double-click FloorForge.bat. First setup installs dependencies; subsequent core use is offline.

What to know before using it

These are developer launchers, not signed native installers. The 3D is a real-time, physically based walkthrough (choose Walk in, click, then W A S D, mouse look, Shift to run, Space to jump, stairs to change floor; ⤢ Large view fills the window, ◎ Focus shows the home alone filling the whole screen, and + / − or a double-click zoom in) — convincing, but not a photograph or path-traced render. Path-traced stills are an optional offline Blender step (Blender GLB button, then scripts/render_cycles.py). Official NBC/byelaw approval, structural design, independent IFC acceptance, the full questionnaire/editor, path-traced cinema and native release validation remain open.

Never use these drawings as construction instructions without competent local professional review.
