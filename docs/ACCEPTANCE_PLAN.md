# Remaining engineering gates and rollback

No blanket “M0–M8 complete” assertion is warranted. Each following item needs an evidence artifact and a reviewer, not just a checked checkbox.

## P0 — before a professional pilot

1. Obtain the actual legacy repository and its tests. Run them untouched; write explicit contract adapters or migration tests. Do not compare 112 new checks to 243 unavailable tests as though counts establish equivalence.
2. Obtain current, applicable BIS/NBC text and local authority rules through authorised sources. Encode clause/edition/jurisdiction/effective-date applicability with PASS/FAIL/NOT EVALUATED. A registered/local professional reviews the rule pack. Retain secondary targets separately.
3. Rework stair arrival/landing/ceiling headroom, structural load paths and accessible routes with actual engineering. Derive member/footing/rebar data only from valid calculations and soil parameters. Until then retain NOT DESIGNED and disable construction-ready outputs.
4. Run `verify_ifc.py` and independent BIM geometry viewing, checking placements, spaces, all opening voids, terrace/stair slabs and dimensions. Fix exporter semantics and re-import across two tools. Record exactly which entities are supported. AutoCAD GUI/DXF dimension fidelity and physical PDF plot scale require independent checks too.
5. Run clean, networked first setup, offline second start and saved-project reopening on actual macOS and Windows. Build/install/uninstall unsigned prototypes, then sign/notarise approved releases. Do not distribute a recipe as a verified binary.

## P1 — homeowner product completeness

Expand `intent.py`/`layout.py` to count/locate rooms across floors, full conditional questionnaire, arbitrary plot polygons, protected trees and surveyed levels. Add constrained layout optimisation rather than overextending the band family. Separate exact manual geometry from suggestions. Add property-based polygon/door/stair tests and an adversarial matrix, including skinny L rooms and infeasible inputs.

Implement a real drag/resize/rotate/snapping editor over semantic IDs, preserving constraints and immutable revisions. Add source-aware undo/redo and diff comparisons. Finish self-contained image/reference persistence. Treat automatic sketch/CV/OCR as an explicit recognition hypothesis with human correction, not ground truth.

For collisions, add capsule/step/headroom and per-floor stair traversal, movable-door state, glass barriers, navmesh/click routes, furniture-clearance checks and motion accessibility. Preserve the existing floor selector as a fallback, not as pretend stair walking.

## P2 — visual and AI acceptance

Build the optional Three/path tracer with a frozen lock; choose whether it replaces the fallback or stays a lab. Create curated license-clean furniture/material/HDRI packs, real section caps, site context and a visible-fixture lighting audit. Render every style on identical plots, plus distinct plots. Run fixed-camera real-GPU colour/exposure/performance checks and reject flat/toy compositions.

Execute the Blender scene worker, inspect the `.blend`, run a geometry-clay pass, repair intersections, curate an eye-height interior route, then render reviewed 4K stills and film. Archive framebuffer/camera/material/scene hashes. A PNG generated by an unrelated image model is not proof the 3D pipeline is photoreal.

Exercise actual local Qwen and cloud credentials with a fixed consent-safe benchmark. Compare accepted proposal quality against engines-only under the same constraints, measuring invalid JSON, rejected edits, explicit contradiction rate, cost, latency and reproducibility. Do not promise every more expensive tier always improves a design. Add OS-keychain opt-in, provider-model discovery and optional vision only after privacy and capability checks.

## Rollback policy

Every experiment belongs in a new version/source branch and a new output build ID. Keep the prior implementation and sample outputs. A failed optional renderer/AI provider must never mutate the active validated project. Cache keys include source/runtime versions; remove only corrupt cache entries after preserving evidence. Do not regenerate over hand-edited professional drawings. Restore the prior release folder and reopen the saved project to roll back.

## Required release evidence

A signed scope ledger; actual test output; CPU/runtime/resource measurements; independent CAD/BIM reports; A3 print-scale check; native browser/GPU captures; screenshots for every renderer/style/mode; source/license/asset manifests; clean-machine installation videos; no-network operation proof; a user-study record. Unexecuted CI, build recipes and artistic intent do not satisfy those gates.
