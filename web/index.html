How much assistance?

Model IDs and prices must be verified on your provider. An unknown price is not zero. Create a scoped project key on the provider site, use it here, then revoke it there. Keys expire in this server after 30 minutes, are never written to disk, and are not included in projects. No OS-keychain storage in this release.

A proposal must pass the available deterministic screen, then you approve it. Structural/regulatory gates are not implemented; no AI proposal is certified.
